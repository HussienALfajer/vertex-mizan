# Vertex Mizan

Professional multi-company accounting system by Vertex. The name comes from *mizan* (الميزان), the balance, as in the trial balance (ميزان المراجعة).

Arabic-first. Vertex Media is the first company on the system and its design partner; Vertex Hub, its operations platform, posts its financial events here.

## Status

Phase 0, the foundation: the monorepo scaffold and CI are in place; the money module, the ledger core, the database guards, the design system and the app skeletons follow (`docs/ROADMAP.md`).
