# Vertex Mizan

Professional multi-company accounting system by Vertex. The name comes from *mizan* (الميزان), the balance, as in the trial balance (ميزان المراجعة).

Arabic-first. Vertex Media is the first company on the system and its design partner; Vertex Hub, its operations platform, posts its financial events here.

## Status

Phase 0, the foundation: the monorepo scaffold, CI, the money module, the ledger core, the database foundation (roles, company isolation, the ledger guards and their tests), the scenario-book runner and the design system for accountants (ADR 0010) are in place; the data grid and the app skeletons follow (`docs/ROADMAP.md`).
